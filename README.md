# Local Library Project
## Project Purpose
Since the creation of a local library, this project establishes a digital dashboard that helps track the status of all books within the library, as well as providing additional statistics.  The goal is for this dashboard to be easy and efficient to use while keeping the contents of the local library organized and up to date. 
## Features
Native array methods find() and filter() have been used in the code of this project.  Additionally, this project successfully uses a ternary operator, a spread operator, object shorthand, array destructuring, and for/in loops.  These JavaScript features make it possible for this local library dashboard to track different data points within the library itself.
